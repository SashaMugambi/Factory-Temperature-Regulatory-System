# Factory Temperature Regulatory System

Arduino-based temperature monitoring and alert system that monitors temperature levels, displays status information on an LCD, and provides visual and audible alerts for different temperature conditions.

### Features

* Temperature monitoring and LCD display
* Green, blue, and red LED status indicators
* Audible temperature alerts using a buzzer
* Serial communication and manual alert control
* Temperature-based alert levels

### Technologies

**Arduino C++ · Tinkercad · LCD · Temperature Sensor · LEDs · Buzzer · Serial Communication**
